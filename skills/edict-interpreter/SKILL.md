# 诏令解释

## 何时使用

调整诏令提示词、工具 schema、规则拒绝、JSON 回退或草案确认行为时使用。

## 输入

场景类别、玩家文本、当前状态摘要、可用 StateOp、预期拒绝与延期条件。

## 步骤

1. 让解释器把每类文本拆成独立条款；明确未知目标或含糊要求需澄清。
2. 只暴露当前合法工具 schema；操作进入规则层后再检查实体、权限、资源与目标。
3. 在回执中保留原文、操作、状态和拒绝原因。
4. 确认前不追加任何状态变更；确认后只持久化通过的操作和明确标记的延期条款。
5. 探测失败时使用 JSON fallback；解析围栏 JSON 后仍须执行同一规则验证。
6. 限制每次最多 12 步，覆盖单次/总超时和中止路径。

## 输出契约

预览收据忠实表达拟执行操作；模型不能越过规则层或在确认前改变状态。

## 涉及文件

`backend/simcore/agent/roles.py`、`agent/tools.py`、`llm/`、`api/app.py`、相关提示词与测试。

## 验证

使用 Mock 覆盖已接受、被拒绝、延期、JSON 回退、未确认不变更与 abort。
