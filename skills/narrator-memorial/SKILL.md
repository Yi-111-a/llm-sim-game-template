# 纪事撰写

## 何时使用

调整回合纪事、离线史官模板、事实文本、终局复盘，或叙事模型的事实边界时使用。（注意区分：剧本里的「奏疏」memorials 是决策条目，见 scenario-design；本技能的「纪事」是回合结束后的叙述。）

## 输入

确定性引擎产出的公开 `TurnReport`：事实（带原因）、对账、战报、事件、危机变化、终局；以及剧本的文风覆盖。

## 步骤

1. 只把已提交的公开报告当作可陈述事实；提示词写明不得补造人物行动、数字、对话、动机或因果。
2. 事实文本在引擎侧就写成人话：显示名而非 id、「国库 −20（北境冬衣）」带原因、隐藏数值写「有所变动（数值不明）」、对称的关系变化只写一次、内部旗标与记账事件不出现。
3. 离线（mock）用史官模板：「是季，朝廷从『北境请饷』之议……」，只组合事实；剧本可用 `chronicle_templates` 覆盖措辞。
4. 场景可在 `prompts/narrator.md` 覆盖文风，但不改事实来源。
5. 远地军报晚到的事实，纪事里按「奏到」叙述，不当作本季发生。
6. 终局复盘（`/view.review`）：命中条件、要事时间线（使结局条件成立之事优先）、终局数值；不再列奏疏与待决事件。
7. MCP client 模式下 end_turn 不附与事实重复的纪事，由调用方模型自行叙述——同样只能用事实。

## 输出契约

简短、可读、仅复述事实的纪事；不产生可执行操作；数字都能在报告里找到。

## 涉及文件

`backend/simcore/agent/roles.py`、`agent/offline.py`、`domain/describe.py`、`domain/visibility.py`、`simcore/prompts/narrator.md`、`chronicler.md`、`scenarios/<id>/prompts/`。

## 验证

给只含有限事实的报告，检查生成文本不增加人物、数字和事件；扫描纪事与日志中无 `�`、无原始 id；隐藏数值不出现确数。
