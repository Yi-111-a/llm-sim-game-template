# 人物扮演

## 何时使用

新增人物聊天、角色记忆、场景人物提示词或 SSE 对话交互时使用。

## 输入

角色 persona、职位、状态、所在地区、已知事实、玩家问题和场景的 afterlife 策略。

## 步骤

1. 先检查人物是否存在、是否存活或允许对话；死者默认拒绝交流。
2. 只向模型提供该人物的身份、当前状态、记忆和相关上下文。
3. 提示模型保持人物口吻，不虚构规则结果，也不直接应用操作。
4. 将用户问题发给选定 `character_chat` provider；通过 SSE 分块返回结果。
5. 记录会话消息但不把叙述性答复当作世界状态。

## 输出契约

有身份边界的对话文本或明确拒绝状态；所有文本都不具备状态操作权限。

## 涉及文件

`backend/simcore/agent/roles.py`、`api/app.py`、`scenarios/<id>/characters.yaml`、前端聊天组件。

## 验证

覆盖存活、死亡、未知人物和空问题；Mock 下验证 SSE 包含状态、消息与结束事件。
